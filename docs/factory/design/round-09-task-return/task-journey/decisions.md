# Task return sources

Eleven additive desktop design scenes finish the bounded return paths missing from Round 08. These are proposed fictional design states. They do not implement an application, provider, connector or authority contract.

The generator imports Round 08 definitions without calling its `main()`, then uses `R8.M.Canvas` with an R9-owned page adapter, control/edge registries and finish method. Shell identity, task heading and active-turn labels are explicit per scene. No R8 file, native frame binding or reaction changes. The manifest binds every R8 file by SHA-256 and checks the same inventory after generation.

The prepared-revision binding records the displayed summary, artifact previews, full reply and meeting proposal; it does not invent a full diagnosis artifact that R8 never supplied.

Reopen retains the same T-084 as idle. R9-T04 shows prior revision-1 acceptance, consumed approval and both receipts inline, with zero new attempts/actions and completed children unchanged. **Close without new work** returns to the same completed parent display without another acceptance or action replay. A follow-up needs new intent within still-valid research-and-drafts scope; a new external write needs a newly reviewed approval. Its future New task/Reopen controls are disabled and explicitly outside the bounded journey in the caption and manifest. ## Reproduction and evidence limits

```powershell
python docs/factory/design/round-09-task-return/task-journey/build.py
python docs/factory/design/round-09-task-return/task-journey/build.py --render
```

The source gate parses SVG XML, checks unique namespaced groups, excludes raster nodes, measures actual Inter ink bounds/pair intersections, verifies container/control/group bounds and explicit destinations, and checks the authored branch/identity invariants. `validation.json` records PASS for all eleven scenes with zero issues. Font source files and their weights are SHA-bound.

The installed Windows renderer cannot provide inspectable Inter font matching. To make the preview font source explicit without installing fonts, `--render` uses existing fontTools to make temporary outlined derivatives from the bound Inter glyphs and PIL prefix advances, then invokes `rsvg-convert`. Authored SVGs remain editable native text. `render-evidence.json` records exact source SVG, font and preview PNG hashes. This derivative rendering does not establish platform font matching, shaping equivalence, native typography or Figma import.

All eleven final PNGs were opened by the source author; regenerated changed variants were reopened. No clipping or text overlap was found in the reviewed images. The manifest's automated `rendered` flag records generation only, not independent native or pointer inspection. Author review is limited to these local preview images.

No application, browser, Figma, native package, gallery, dev server, provider, integration, CI lane, hosted build, install, commit or PR was run by this source author. The parent's later [native evidence](../native-evidence.json) separately records the November 5 import, visual inspection and fifteen pointer checks. Runtime, functional input, persistence, connector reliability, mobile and accessibility remain unqualified. All task, person, note, assignment, time, acceptance and receipt values are fictional.
